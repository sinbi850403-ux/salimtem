개인정보처리방침

시행일: 2026년 10월 11일

「오늘의 살림템 업로더」(이하 "도구")는 YouTube 채널 「오늘의 살림템」 운영자가 본인 채널에 영상을 업로드하기 위해 사용하는 개인용 도구입니다. 이 방침은 도구가 다루는 정보와 그 처리 방식을 설명합니다.

1. YouTube API Services 사용

도구는 YouTube API Services를 사용합니다. 도구를 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, Google의 정보 처리에는 Google 개인정보처리방침이 적용됩니다.

2. 접근하는 정보

  • OAuth 인증 토큰: 운영자 본인 채널에 영상을 업로드하는 권한(youtube.upload, youtube)을 위해서만 사용합니다.
  • 업로드하는 동영상과 제목·설명·태그·예약 시각: 운영자가 직접 제작한 콘텐츠입니다.

도구는 운영자 외 다른 사용자의 개인정보, 시청 기록, 구독 정보, 댓글 등을 수집하거나 조회하지 않습니다.

3. 정보의 이용

위 정보는 운영자 본인의 YouTube 채널에 동영상을 업로드하고 썸네일·공개 예약을 설정하는 목적으로만 사용합니다.

4. 저장 및 보관

OAuth 토큰은 운영자만 접근할 수 있는 비공개 저장소의 암호화된 비밀 값(GitHub Actions Secrets)에 보관하며, 도구 사용을 중단하면 삭제합니다. 업로드 기록(업로드 시각, 동영상 ID)은 운영 관리 목적으로 같은 비공개 저장소에 보관합니다.

5. 데이터 삭제

  • OAuth 토큰: 도구 사용을 중단하거나 권한을 철회하면 즉시 삭제합니다. YouTube API를 통해 얻은 인증 정보는 30일 넘게 사용하지 않고 보관하지 않습니다.
  • 업로드 기록: 운영자의 요청 또는 도구 사용 중단 시 삭제합니다.
  • 삭제 요청이나 문의는 아래 이메일로 보내 주시면 7일 이내에 처리합니다.

6. 제3자 제공

도구는 어떠한 정보도 제3자에게 판매하거나 제공하지 않습니다. 동영상과 메타데이터는 업로드를 위해 Google(YouTube)에만 전송됩니다.

7. 권한 철회

도구에 부여한 접근 권한은 언제든지 Google 계정 보안 설정에서 철회할 수 있습니다.
