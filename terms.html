1. 목적

「오늘의 살림템 업로더」(이하 "도구")는 YouTube 채널 「오늘의 살림템」 운영자가 본인이 제작한 영상을 본인 채널에 업로드하기 위한 개인용 도구입니다. 외부에 서비스로 제공되지 않습니다.

2. YouTube 약관 준수

도구는 YouTube API Services를 사용하며, 도구의 사용은 YouTube 서비스 약관과 YouTube API Services 개발자 정책을 따릅니다.

3. 콘텐츠

업로드되는 영상의 제작과 내용에 대한 책임은 운영자에게 있습니다. 제휴 링크가 포함된 영상에는 경제적 이해관계를 설명란에 표시하고 YouTube의 유료 프로모션 표시를 적용합니다.

4. 개인정보

정보 처리에 관한 내용은 개인정보처리방침을 따릅니다.
